# 电商平台优惠券系统需求文档

## 业务背景

为电商平台开发优惠券管理功能，支持用户领取优惠券并在下单时使用。

## 业务流程

### 1. 用户登录
用户使用账号密码登录系统，获取访问令牌（Token）。所有后续操作需要在请求头中携带 Token。

### 2. 优惠券领取
已登录用户可以查看可用优惠券列表，选择并领取优惠券。每个用户对同一优惠券只能领取一次。

### 3. 下单使用优惠券
用户创建订单时可以选择已领取的优惠券进行抵扣。系统需验证优惠券的有效性（未过期、未使用、满足使用条件）。

### 4. 订单查询
用户可以查看自己的订单详情，包括优惠券抵扣金额。

## 用户角色

### 普通用户
- 登录/登出
- 查看优惠券列表
- 领取优惠券
- 创建订单
- 使用优惠券
- 查询订单

### 管理员
- 管理优惠券（创建、编辑、下线）
- 查看所有订单

## 业务规则

1. 每个用户对同一优惠券只能领取一次
2. 优惠券有有效期，过期不可使用
3. 订单金额必须大于 0
4. 优惠券抵扣金额不能超过订单总金额
5. 已使用的优惠券不可再次使用
6. 取消订单后优惠券应返还

## 异常场景

1. 未登录用户无法访问需要认证的接口（返回 401）
2. 重复领取同一优惠券应提示错误
3. 使用已过期的优惠券应提示错误
4. 使用不存在的优惠券码应提示错误
5. 订单金额为 0 或负数时应提示错误
6. Token 过期后应提示重新登录
